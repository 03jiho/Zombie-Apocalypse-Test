# 생존자 기록부 — 좀비 아포칼립스 성격 테스트

죽은 자들이 다시 일어선 도시에서, 15개의 상황 속 당신의 선택을 추적하는 인터랙티브 성격 테스트입니다.

🔗 **플레이하기**: https://03jiho.github.io/Zombie-Apocalypse-Test/

## 기능

- 15개의 상황극 문항. 처음 두 문항에서 무기(권총/소총/산탄총/활)와 방어구를 고르며, 이후 실제로 무기를 쓰는 장면들의 문장이 고른 무기에 맞게 달라집니다.
- 4번 문항에서 무리에 합류할지, 직접 나서서 사람들을 이끌지, 혼자 다닐지 정하며, 이후 문항의 서술과 선택지가 그 경로(파티/리더/솔로)에 맞춰 갈라집니다.
- 도덕성(X)·소속감(Y) 두 축으로 12개 결과 유형(피에 젖은 계산가, 잿더미의 지배자, 마지막 등불지기 등) 중 하나로 판정됩니다. 리더 경로로 마지막 위기 문항에서 시간 초과로 아무것도 정하지 못하면, 이 12종과 별개인 히든 엔딩("우유부단한 리더")이 뜹니다.
- 동료 신뢰도 게이지, 되돌릴 수 없는 선택 경고, 18초 제한시간 분기, 선택 직후 잠깐 떴다 사라지는 통계 연출이 있습니다.
- 결과 화면에는 5축 레이더 차트(생존확률/인간성/카리스마/잔혹함/신뢰도), 정반대 유형 매칭, 전체 유형 생존 랭킹, 공유용 카드, 두 유형을 골라 배신 확률을 계산하는 생존 궁합 모드가 포함됩니다.

## 기술

순수 HTML + React(UMD, CDN) + Babel standalone(JSX 변환)으로 작성됐고 빌드 과정이 없습니다. 별도 서버 없이 `index.html` 파일 하나로 동작해요. 상태는 세션 메모리에만 남고 저장되지 않습니다.
